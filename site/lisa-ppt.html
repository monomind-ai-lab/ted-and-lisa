Both are made by MonoMind AI Lab, and both put the same brand on the page. They are not the same product, and this page exists so the gallery does not have to pretend otherwise.

Install

Two commands, once.

Lisa's PPT is a plugin, installed the way any other plugin is. Run these two in this order, and /lisa-ppt becomes a standing command.

01Add the marketplace

The repository is its own marketplace, so this is the step where your agent learns the plugin exists.

/plugin marketplace add monomind-ai-lab/lisa-ppt
02Install the plugin

Installed once, available in every project. Other agents have their own plugin directory — the layout is the same.

/plugin install lisa-ppt@monomind-ppt

Where they run

Both lines are typed at your agent, not in a terminal. The wording is Claude Code's; other agents install a plugin their own way, from the same repository.

Claude CodeCodexGemini CLIOpenCode

Those two lines are commands, not prose. They are never translated, whatever language this page is switched to — a mistranslated command is a command that does not run.

The workflow

Brief it, and it builds the deck.

Nothing new to learn if you have used /lisa. It asks for the same brief and it applies the same brand — it just ends somewhere else.

01

Tell it what the deck is for

The same brief Lisa takes: what this is about, who it is for, what it has to do when it lands. Those answers are its own first stage.

02

It builds in the house style

The MonoMind brand pack ships with it, so the deck comes out looking like everything else here without you supplying a single token.

03

You get a .pptx

Open it, edit it, send it. From that point it is a PowerPoint file like any other, and this site is not involved in it at all.

Every step above happens in your own agent, on your own machine. This site describes the plugin; it does not run it, and it never sees the deck.
